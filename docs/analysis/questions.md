# PREPARAÇÃO PARA A BANCA

### 1. Por que escolheram o SAML-D?

O SAML-D foi escolhido por disponibilizar milhões de transações financeiras, diferentes modalidades de pagamento, moedas, localizações bancárias e exemplos de comportamentos relacionados à lavagem de dinheiro.

Isso permite explorar diferentes características das operações e desenvolver modelos de classificação para identificar transações suspeitas.

No entanto, por ser sintético, ele permite experimentar e avaliar metodologias, mas não comprova que o modelo terá o mesmo desempenho em transações bancárias reais.
